### 🤖 O que eu faço

Construo robôs que tiram trabalho manual e repetitivo das empresas. Processos que levavam **horas ou dias passam a rodar em minutos**, com menos erro humano e dados confiáveis no fim.

- **RPA em Python** — robôs web e desktop que acessam portais e sistemas, baixam documentos, preenchem dados e enviam resultados sozinhos.
- **Orquestração e integração** — n8n, APIs REST, webhooks e PostgreSQL ligando sistemas que não conversam entre si.
- **Agentes de IA** — LLMs integrados a ferramentas via MCP, com aprovação humana (*human-in-the-loop*) onde a decisão importa.
- **Do processo à produção** — mapeamento do processo, documentação, deploy em containers e monitoramento.

### 🛠️ Como eu trabalho

```
mapear o processo → priorizar pelo ganho → automatizar → testar → publicar → monitorar
```

1. **Entendo a dor** com quem executa o processo e estimo o ganho antes de escrever código.
2. **Automatizo** com a ferramenta certa para o caso: Python puro, low-code ou IA.
3. **Deixo pronto para rodar sozinho**: logs, tratamento de erros, credenciais em cofre de senhas e execução headless em Docker.
